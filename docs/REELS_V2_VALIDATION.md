# HEADLINE 60 뉴스 릴스 고도화 검증 — 2026-10-30

## 결과와 기존 구조
기존 FastAPI/Jinja2/Vanilla JS·SQLite·Ollama·TTS·FFmpeg를 유지했다. 뉴스 탐색→근거 확인→대본 편집/승인→기존 단일 작업 큐→MP4/ZIP 흐름에 3종 릴스 렌더러를 연결했다. 기존 CLI·카드 출력·취소·실패 재개를 보존했다. 아나운서는 주요 UI에서 제외하고 실험 파일/모델/읽기 전용 과거 기록을 보존했다. start/stop/restart/status/logs 기존 스크립트를 재사용했고 독립 Ollama를 종료하지 않았다.

## 주요 변경 파일
- `app/script/models.py`, `app/studio_models.py`: 스토리보드·템플릿·차트 스키마, 출처/수치/기준일 검토.
- `app/llm/news_writer.py`: 실제 근거 기반 스토리보드 프롬프트, 출처 ID 필수 스키마와 정규화.
- `app/media/library.py`, `app/media/api.py`: SQLite 자산·사진/영상/음악 업로드·권리/형식/크기/경로/해시 검사.
- `app/renderer/reels.py`, `app/renderer/storyboard.py`: 모션·3레이아웃·자료 선택·음성 기준 타이밍·장면 캐시.
- `app/tts/engine.py`, `app/tts/profiles.py`: 승인된 Sohee 설명 말투와 연속 장면 발화, 음성 캐시.
- `app/jobs/pipeline.py`, `app/jobs/manager.py`, `app/main.py`: 기존 큐/검토/재개 통합, 자산 스냅샷, 실제 길이·출처·출력 다운로드.
- `templates/index.html`, `static/app.js`, `static/style.css`: 3템플릿·자료/음악·스토리보드·차트 편집·샘플 갤러리.
- `tests/test_reels.py`, `tests/test_reels_v2.py`, `tests/test_reels_workflow.py`, `tests/test_media_library.py`: 추가 검증. 기존 아나운서 API 테스트의 UI 캐시 버전 표기만 현재 값으로 갱신.

## 실제 영상 효과
브랜드 네이비/코랄/오프화이트/슬레이트를 적용했다. 큰 제목과 하단 내레이션 자막을 분리하고 페이드 입장/퇴장, 상하 슬라이드, 확대·축소, pop, 단어 순차 등장, 수치 강조, 중립색→코랄 전환, 반투명 자막 배경을 구현했다. 스틸은 교대 줌 인/아웃·좌우 팬과 선택적 가벼운 블러를 지원한다. 영상은 원본 오디오를 버리고 루프/9:16 크롭한다. fade/wipe는 장면 초반 배경 진입 효과이며 인접 영상의 겹침 전환은 아니다.

- HEADLINE NEWS: 실사 자료 위 큰 제목과 짧은 핵심 전달.
- STORY EXPLAINER: 단계 번호·네이비 설명 패널·문장 전개.
- DATA COMPARISON: 밝은 패널·근거 기반 막대 비교·0.4초 차트 등장. 중간 가짜 숫자 카운트 없이 최종 값을 고정한다. 차트 데이터가 없으면 설명 그래픽이다.

## 미디어와 권리
PNG/JPEG/WEBP, MP4/MOV, MP3/WAV를 지원한다. 최대50MiB, 이미지2400만 픽셀, 영상 긴 변4096px/300초 제한. EXIF 방향 보정·메타데이터 제거, 승인/미승인 상태와 출처·저작자·라이선스·SHA256을 SQLite에 저장한다. 승인된 자료만 렌더링하고 재개 시 파일 해시를 재검사한다. 권리 확인은 사용자 기록이며 법적 자동 증명이 아니다.

기본 실제 아파트 사진 2장은 Wikimedia Commons CC BY-SA 4.0이다. 자동 검색·무단 크롤링을 하지 않으며 등록된 카테고리 자료를 재사용하고 없으면 자체 그래픽으로 대체한다. 특정 사건/단지의 사진으로 주장하지 않는다. 출력 `media-sources.json`, `CREDITS.md`에 원본 링크·라이선스·변경 표시를 포함하며 CC BY-SA 자료가 들어간 편집물은 같은 조건으로 제공한다.

## 브라우저 사용
`./start.sh` → http://127.0.0.1:8060/ 의 3가지 릴스 템플릿 미리보기. 새 뉴스는 뉴스 탐색→선택→근거/대본→템플릿·자료·음성→저장/검토 승인→영상 생성. 제작 내역에서 MP4/게시ZIP/전체 대본/출처/자막 편집을 이용한다.

## 한계와 다음 단계
- 기본은 승인한 설명 말투·속도1.0으로 음성에 화면 길이를 맞춘다. 30/60초는 목표이며 실제35~39초처럼 달라질 수 있다. 사용자가 뒤이어 더 빠른 말속도를 요청해1.18배 짧은 비교 시안을 만들었으며 피드백 전 전체 기본 속도를 바꾸지 않았다.
- 연속 발화의 구절 자막은 문자량 기반 표시 시간 추정이다. 단어 강제 정렬이 아니며 자막 편집에서 교정할 수 있다.

- 숫자/출처 검사는 휴리스틱이다. 단위·비교 조건·문장 의미는 사용자가 원문과 대조해야 한다. 현재 ChartData는 비음수2~6항목 막대 비교만 지원하며 음수 변동률은 설명 화면을 사용한다.
- 음악은 권리가 확인된 로컬 파일을 선택할 때만 낮은 볼륨과 ducking으로 합성한다. 음악 없어도 정상 제작된다.
