## 기존 영상 분석과 우선순위
최근 실제 뉴스 샘플3개의24개 대표 프레임을 확인했다. 전체 감사는 `data/quality-v3/before-audit/AUDIT_KO.md`, 정량값은 같은 폴더 audit.json에 보존했다.

1. 제목과 자막을 크게 반복해 사진을 가리며 데이터형에는 차트가 없는 장면에도 넓은 빈 패널이 남았다.
2. 첫 제목 완성 이후2초간 변화가 적었고, 초반 후킹과 본문 강조의 역할이 분리되지 않았다.
3. 사진2장을 최대3회 반복하고, 실제 금리 내용에 금융 배경이 없는 장면이 많았다.
4. 자막은2줄/끝시간은 맞지만 문자량 기반 구절 타이밍이며 단어별 싱크가 아니었다.
5. 남색/코랄과 한글 글꼴은 일관됐으나 작은 출처와 추상적인 카드의 비중이 높았다.

## 구현한 시청 경험 개선
- 첫2초 전용 Hook: 원문을 자르지 않는 최대2줄 큰 제목, Pop과 핵심 단어 코랄 강조. 제목과 반투명 판이 함께 사라지도록 대표 프레임에서 발견한 빈 패널 문제도 수정했다.
- 일반 실사 장면은 큰 중복 제목을 줄여 실제 배경과 내레이션 자막을 중심으로 표시한다.
- v3의 fade는 이전 순수 배경 마지막 프레임과 다음 배경의0.16초 실제 블렌드다. 이전 자막을 섞지 않으며 장면·오디오 시간은 이동하지 않는다. 차트·cut 선택은 하드컷을 유지한다.
- Clean News와 Dynamic Reels를 선택할 수 있다. Dynamic은38~44px 범위, 최대2줄, 네이비 반투명 판, 구절 Pop·숫자/핵심 단어 코랄 강조를 사용한다. 자막 편집 저장과 실제 렌더 검사가 같은 글꼴/안전영역을 사용한다.
- 기존 zoom in/out·좌우 pan·Slide Up·숫자 Scale·단어 순차 등장·선택적 블러를 재사용하며 장면 유형에 따라 배치한다.
- 자동 자료는 시각 검색 메모+등록 자료 이름/키워드/설명으로 고른다. 승인 자료만 허용하고 자동 선택에서 동일 자산을 최대2회 사용하며 가능하면 연속 반복을 피한다. 명시적으로 고른 사용자 자료는 그대로 사용한다. 맞는 자료가 없으면 그래픽이다.
- 장면별 자동/수동 사진·영상 썸네일을 웹에 표시한다. 저장된 대본의 자동 추천이며 저장 전 수정이나 이후 렌더의 선택을 확정하는 것은 아니다.
- 사이트에서1.00~1.35배 음성 속도를 저장한다. 새 제작 기본1.18배이며 이전 대본/CLI는1.00배 호환값이다. 음색을 바꾸거나 TTS를 다시 추론하지 않고 캐시 음성을 후처리해 화면/자막 길이를 함께 맞춘다.
- 연속 발화 자막은 발음용 문자열 길이로 추정한 경계를 실제 조용한 구간±280ms에 맞춘다. 단어 강제 정렬은 아니며 수동 교정이 가능하다. 기존 편집 자막은 검토 당시 속도를 기록해 속도 변경 시 비례 조정한다.
- 기존 TTS의 선두/말미 무음 정리·음량 정규화·클리핑 검사를 유지했다. 음악은 로컬 권리 확인 파일만 선택하며 낮은 볼륨/ducking/리미터를 거치고, 음악이 없어도 정상 제작된다. 이번 비교 영상에는 음악을 넣지 않았다.

## 콘텐츠 모드3종
- **실제 뉴스(news)**: 기존 기사 선택·공식/허용 근거·숫자/날짜/출처 검토를 그대로 사용한다. 기사 없이 실제 뉴스를 만들 수 없다.
- **건강·외모·연애 속설 검증(myth_check)**: 주제 또는 기사로 작업을 준비하고, 공식 근거를 보완한 다음 초안을 생성한다. 근거가 없으면 앱이 생성/승인을 막는다. 모델이 검증 기관인 것처럼 참/거짓이나 건강 효과를 임의 단정하도록 하지 않는다.
- **성인 공감 풍자·코미디(adult_satire)**: 주제와 명시적 허구 확인으로 시작한다. 뉴스 근거 없이 창작할 수 있지만 가짜 통계/사실 차트/의학 효과 단정은 금지한다. 영상 모든 프레임에 renderer가 소유하는 `허구 · 성인 공감 풍자` 라벨을 넣으며 모델 문구로 제거할 수 없다. 새 모드를 이 표시가 없는 구형 카드 렌더러로 보내는 것도 차단한다.

두 새 모드는 현재 대본 버전의 콘텐츠 검토가 필요하다. 속설 모드 및 의료로 감지한 내용은 의료 근거/표현 확인, 성·연애 관련 표현으로 감지한 내용은 별도 검토 확인란을 서버에서 요구한다. 내용/자막/설정을 저장하면 승인이 해제되고 이전 버전의 검토를 재사용할 수 없다. 의료/성 판별은 보수적인 키워드 규칙이며 누락·과탐 가능성이 있다. 검토 체크는 의학적 진단이나 전문기관의 인증이 아니다.

모든 업로드는 사용자가 직접 한다. 게시 API/예약 게시 기능은 없다. 개발 샘플은 `sample_pending_user_review`, `review_required`로 표시했으며 사용자가 게시 승인한 결과라고 보고하지 않는다.

## 사용자가 확인할 부분과 한계
- 이번3개 뉴스는 날짜가 명시된 기존 공식 발표를 사용한 비교 샘플이며 새로 취재한 최신 속보가 아니다. 공식 출처는 각 sources.json/CREDITS.md와 docs/REELS_V2_VALIDATION.md에 보존했다.
- 같은 대본을 유지해 디자인만 비교했으므로 기존 대본의 설명 비중/흥미는 그대로 남는다. 새 생성 프롬프트에는Hook→Context→Facts→Meaning→Conclusion을 적용했다.
- 30/60초는 목표이며 실제 음성에 따라 길이가 다르다. 설명형은1.18배에서28.9초다. 엄격한30초 이상이 필요하면 대본을 보완해야 하며 억지 감속하지 않는다.
- 자료는 등록된5개만 재사용했다. 부동산 사진2장/금융 사진2장+실제ATM영상1장이다. 자동 온라인 스톡 검색은 없으며 부족하면 그래픽이다. 해외 금융 화면은 별도 표시한다.
- 자막은 실제 휴지를 참고하는 추정이다. 특히 긴 숫자/이름, 끊어 읽기, 첫/마지막 음절은 직접 재생해 확인해야 한다. 단어별 강제 정렬은 아니다.
- 테스트 통과/대표 프레임 검토는 인스타그램에 어울리는 미적 품질이나 의학적 사실 확인 완료를 뜻하지 않는다. 모바일 기기로 후킹·가독성·전환·전체 청취를 평가해야 한다.
- 다음 우선순위는 사용자 영상 선호 확인, 장면에 맞는 로컬 자료 확충, 긴 수치/지명 발음·자막 미세 교정이다. 새 모델이나 플랫폼 확대보다 이 검수를 먼저 한다.
