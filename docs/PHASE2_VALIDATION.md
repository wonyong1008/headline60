# Phase 2 실제 검증 — 2026-10-28 (Asia/Seoul)

## 범위와 기존 기능 보존

Phase 1의 FastAPI/Jinja2·SQLite·뉴스 근거 검토·대본 승인·기존 TTS·VideoToolbox 렌더러·취소/재개를 확장했다. 기존 33개 테스트와 이전 결과 파일은 보존했다. 이번 작업은 서버 관리 → MLX 한국어 음성 → 발음·구절 자막 → 720p 통합 검증 순서다. AI 진행자·의상·립싱크는 구현하지 않았다.

## 서버 관리 실제 실행

프로젝트 루트 `start.sh`, `stop.sh`, `restart.sh`, `status.sh`, `logs.sh`와 `scripts/services.py`, `service_runner.py`, `app/serve.py`를 추가했다. `dev.sh`와 `ollama.sh`의 동작은 유지하고 공통 API 진입점을 재사용한다.

- 최초 시작, 중복 시작, 상태 조회, 로그 조회, 종료·재시작을 실제 실행했다.
- 시작 호출 부모가 끝나고 별도의 터미널 호출에서도 API가 같은 PID로 정상 응답하는 것을 확인했다. 프로세스는 분리된 세션과 파일 로그를 사용한다.
- HEADLINE 60이 직접 기동한 API를 강제 종료한 뒤 `start.sh`로 재기동하고 health를 확인했다.
- 기존 독립 Ollama PID 68617을 재사용하고, API 종료·재시작·복구 후에도 해당 Ollama를 보존했다.
- PID 파일만 신뢰하지 않고 전체 실행 명령·시작 시각·고유 instance를 대조한다. 자식도 소유 계보를 확인한 시점의 identity와 현재 identity가 같을 때만 정리한다.
- 잘못된 PID/JSON·PID 재사용·외부 프로세스 보호·기동 실패 정리·로그 처리 등은 별도 단위 테스트로 검증했다. 이 테스트에서는 실제 프로세스를 kill하지 않는다.
- 실제 Mac 재부팅·물리 Terminal 앱 종료·뚜껑 닫기/잠자기 상태는 재현 실험하지 않았다. 실행 부모 종료 후 유지와 프로세스 비정상 종료 복구가 확인된 범위다. 로그인 자동 실행은 등록하지 않았다.
- 정상 기동 후 기본 브라우저 열기를 제공하며 `--no-browser`로 생략할 수 있다. sudo나 시스템 Python/Homebrew 기본 링크 변경은 없다.

## 음성·발음·프로필

고정 한국어 preset **Sohee**로 Female News Anchor, Calm Economic News, Bright Lifestyle News, Energetic Trending News 프로필을 저장했다. 사용자 피드백에 따라 기본 Female News Anchor는 성숙하고 낮은 자연스러운 음역·절제된 감정·안정적인 말끝을 지시하며 속도 0.96을 사용한다. 다른 실제 인물의 참조 음성을 사용하거나 복제하지 않았다. 한국어 남성 고정 화자는 검증되지 않아 선택지에 노출하지 않는다.

- 실제 스타일 샘플 4개는 약 6.24~6.64초, 성숙한 톤 실험 원음은 6.72초다.
- `data/tts_samples/styles/*-normalized.wav`, `data/tts_samples/mature/sohee-mature.wav`에서 비교할 수 있다.
- UI에서 저장된 샘플 듣기·임의 문장 샘플 생성·엔진/프로필 선택을 제공한다. 실패 시 선택한 프로필과 오류를 유지하며 몰래 macOS 목소리로 대체하지 않는다.
- 초기 낮은 temperature 실험은 40초 출력 중 긴 무음을 발생시켰다. `data/tts_samples/initial/`의 출력은 정상 샘플로 취급하지 않는다. 배포 설정의 temperature 0.9/top_p 1/top_k 50으로 재검증한 후 정상 종료를 확인했다. 토큰 한도 도달·긴 무음·작은 신호·클리핑 검사를 추가했다.
- 발음용 텍스트는 원문과 별도다. 날짜/유월·시월, 금액, 소수·음수 비율, 건수, 일부 영문 약어/차량 모델명을 처리한다. 의약품·낯선 지역/아파트 이름은 임의로 바꾸지 않는다. 자동 발음 결과는 장면별 구절 한 줄씩 수정 가능하다.
- 모델은 작업별 별도 프로세스로 실행하고 종료한다. 프로필/모델 revision/seed/생성 파라미터/속도를 기록하고 음성 구절별 콘텐츠 해시 캐시를 사용한다.

## 실제 측정: 캐시 없는 합성

원음 길이와 목표 영상 길이를 구분한다. RTF는 해당 작업의 실제 합성/후처리 경과를 원음 길이로 나눈 값이며 작을수록 빠르다.

| 실제 뉴스 30초용 Sohee | 37.283초 | 31.169초 | 0.836 | 3.129초 | 12/0 |

- Sohee 60초 점검 worker의 순수 생성 합계는 45.034초, worker 전체는 48.122초다. 호스트 품질 검사·정규화 등을 포함한 음성 단계가 52.356초다.

- Phase 1의 기존 TTS 4.326초는 6장면 방식이며 이번 구절별 합성/후처리와 부하가 다르다. Sohee 31.169초와 엄밀한 동등 벤치마크처럼 비교하지 않는다.
- 이 수치는 사람이 느끼는 자연스러움·아나운서 품질의 점수가 아니다. 반드시 전체를 직접 들어 평가해야 한다.

## DB와 후속 Phase 3

SQLite를 유지하고 voice_profiles·voice_samples를 기존 연결 방식으로 추가했다. 미디어는 DB BLOB에 넣지 않고 경로와 메타데이터만 저장한다. 향후 PostgreSQL 전환 시 `?` 바인딩, `PRAGMA table_info` 마이그레이션, `INSERT OR IGNORE`, `rowid` 정렬, JSON TEXT 저장 및 연결/트랜잭션 처리가 이식 대상이다. 이번에는 ORM 전환이나 DB 교체를 하지 않았다.

Phase 3 요구사항은 다음과 같이 보존한다:

- 독자적인 가상의 **성인** 여성/남성 진행자, 고정 얼굴과 현재 voice_profile_id 연결.
- 60초 영상은 도입 약 8초·마무리 약 7초만 진행자, 중간은 자료 화면, 전체에 같은 내레이션 유지.
- 참조 이미지와 검증된 의상별 기본 영상을 재사용해 얼굴·목소리 일관성을 확인한다.
- 부동산 고급 오프숄더 드레스, 경제 V넥·슬림핏, 건강 슬리브리스 웰니스, 자동차 쇼호스트, 핫이슈 글래머러스 스타일. 성인 패션 표현 범위로 한정하고 나체·노골적 성적 표현은 제외한다.
- 스타일 Level 1 Stylish / **기본 Level 2 Glamorous** / 명시 선택 Level 3 Bold Glamour.
- 실제 인물 얼굴·목소리를 무단 복제하지 않고 AI 가상 진행자임을 표시한다.
- MuseTalk Apple Silicon 호환성·5초→10초→15초 처리 시간·메모리를 별도 검증한다. 입술 움직임이 몸짓까지 만든다고 가정하지 않는다. 실패 시 기본 카드 뉴스 제작으로 돌아갈 수 있어야 한다.

## 현재 제약

음성 자연스러움·성숙한 느낌·성공적인 발음은 인간 청취가 필요하다. 캐시 자동 정리·물리 재부팅/잠자기 내구성 실험·남성 한국어 고정 화자·실사형 진행자·의상·립싱크는 완료한 기능이 아니다. 1080p 옵션은 보존했으나 이번 실제 출력은 사용자 요청에 따라 720p까지만 생성했다.
